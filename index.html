모바일 보안 솔루션 리버싱 — MB_BYPASS

인가된 모바일 보안 평가를 위한 멀티에이전트 리버싱 자동화 도구와 판단 규율. Java(jadx)+Native(.so, Ghidra) 탐지 로직을 병렬 분석하고 Frida로 런타임 검증하며, 실측과 추정을 구분한 평가 리포트를 생성한다.

작성자 arahan · github.com/temasa0810 · 윤리·인가 고지

MB_BYPASS 도구 · 방법론 · 판단 규율

상용 RASP·안티치트 분석의 목적은 "뚫었다/못 뚫었다"가 아니라, 실제로 악용 가능한 약점을 정확히 가려내 방어 개선의 근거로 잇는 것이다. 정적 경로의 존재와 런타임 실발동을 분리하고, 실측 없는 판정은 "미규명"으로 남긴다.

RASP (Runtime Application Self-Protection) — 앱 내부에 통합되어 런타임(실행) 중 루팅·후킹 등 보안 위협을 실시간으로 탐지·차단하는 상용 보안 솔루션.

안티치트 — 게임 클라이언트의 메모리 변조·치팅을 탐지·차단하는 보호. RASP와 기법이 대부분 겹친다(상용 안티치트·보안솔루션).

후킹 / Frida — 실행 중인 앱의 함수를 가로채 동작을 관찰·변경하는 동적 분석 기법과 대표 도구.

IL2CPP — Unity 게임을 C++ 네이티브로 변환해 컴파일하는 빌드 방식. 코드가 기계어가 되어 정적 분석 난도가 크게 오른다.
